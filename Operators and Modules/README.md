# Topics to be Covered
- print function<p>Print function is a built-in python function used to display the output.</p>
- input function<p>Input Function always take value in String Format</p>
- variables<p>Variables are containers to store value for future use</p>
- comments<p>A piece of code which is not executable by the compiler and interpreter</p>
- literals<p>A piece of code which is not executable by the compiler and interpreter: Numeric Literals, String Literals, Boolean Literals, Special Literals</p>
- keywords<p>In programming, a keyword is a word that is reserved by a program because the word has a special meaning. Keywords can not be used as a variable names</p>
- basic data types (string, int, float, boolean, complex)
- Identifiers:<p>A python identifier is a name used to identify a variable, function, class, module or other objects</p>
